[P1.1] Antitrust law does not care what tool you use to collude. It cares about the harm: eliminating independent pricing to raise costs above competitive levels. If ten landlords meet in a conference room and all agree to set the same rent, everyone accepts this is illegal price fixing. If those same ten landlords all plug their vacancies into the same black box algorithm that outputs uniform, above-market rent recommendations, and every one of them follows those recommendations, the outcome for tenants is identical.
[P1.2] There is no meaningful economic difference. These tools are not neutral calculators. They do not just analyze local data for an individual landlord. They are built to pool real-time vacancy and pricing data across every competing landlord in the area, then issue coordinated guidance that no single landlord would ever choose on their own.
[P1.3] We have already seen this play out: when these tools roll out in a city, average rents often jump overnight, not because demand shifted, not because building costs rose, but because independent competition vanished. Opponents will argue landlords never explicitly agreed. That is a loophole, not a defence. Antitrust was never written only to catch handshakes in smoke-filled rooms.
[P1.4] It exists to stop the harm caused when competitors stop competing. If a shared tool removes the need to ever negotiate an agreement out loud, that is not an excuse. That is exactly the scenario where antitrust scrutiny is most necessary. We do not allow cartels to avoid consequences just because they outsourced their coordination to software.
[P1.5] The same standard must apply here.
