[P1.1] Real-time face recognition is not "investigation faster." [P1.2] Start with the structure. A warrant requires a suspect, a crime, a particularity — a named person, a specific investigation, a judge testing whether there is probable cause. [P1.3] The only way to run real-time recognition is to sweep the innocent along with the guilty and sort it out later. That is a general warrant against the public at large, and it is the paradigm Fourth Amendment violation, not a policy preference.

[P1.5] Post-incident use with a warrant does not do this — it asks "who is in this specific frame, in this specific crime?" Real-time use asks "who is where, always?" The chilling effect on association and speech falls almost entirely on the banned side of the line.

[C1.2] A categorical ban forbids that use exactly when it matters. If a camera sees a missing teenager at 9:02, the point is not naming her at noon from stored footage; it is reaching her before she is moved or harmed. The same holds for stopping a fleeing violent suspect before a second attack. Delay is not a liberty safeguard there.
[C1.3] It is the difference between prevention and documenting a tragedy after the fact.
[C1.4] The line also collapses logically. Police can record public places, keep the footage, and under this proposal run the same algorithm later with a warrant. The faces scanned, anonymity lost, and movements revealed are identical; only the clock changes. If that identification is a general sweep, a later warrant does not un-sweep the crowd.
[C1.5] If it is legitimate targeted identification, it does not become illegitimate because the match arrives while help can still matter.
[C1.6] The warrant promise is weakest where it is offered. Post-incident suspects are usually unknown, so an application cannot name the person to be identified; the result creates the target. [C1.7] Errors and chilling effects justify strict rules — tiny watchlists, instant deletion of non-matches, no stop on a match alone, audits, and no scanning protests. They do not justify prohibiting the version that can prevent harm instead of merely recording it.
