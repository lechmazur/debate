[P1.3] Start with enforcement. [C1.2] An assignment exists to force a cognitive sequence: choose a claim, order evidence, write a sentence that did not exist, notice it is weak, rewrite it. Generative AI produces the draft, the structure, the tone, the counterargument. Attaching prompts does not put those operations back in the student's head. It grades a confession.
[C1.3] Hidden use and disclosed outsourcing fail the same test: the student did not do the work being graded.
[C1.4] The enforcement problem does not vanish under transparency. If detectors fail, so do self-reported process files. A student can generate the essay first and invent a prompt history afterward. The same tool that wrote the paper can write the reflection.
[C1.5] Disclosure without independent verification is a ritual, not a safeguard.
[C1.6] The calculator comparison is a category error. A calculator yields a number you still interpret. Spellcheck flags a misspelling. Wikipedia is a source you must read.
[C1.7] Generative AI supplies the artifact itself—the essay, the analysis, the lab discussion. Treating a ghostwriter as a calculator is how schools stop measuring writing.
[C1.8] Default permission changes homework. Once AI is allowed if cited, the rational student uses it every night and saves unaided work for rare in-class tests. Teachers cannot orally defend every take-home paper. That "vast middle ground" is where independent practice used to live.
[C1.9] Surrendering it abandons the work that produces the skill. Equity does not save this. Open use still favors students with better models and adult help packaging a process trail.
[C1.10] If a teacher wants AI for a particular task, she can allow it. The default should remain that submitted work is the student's unless the assignment says otherwise. A citation sticker is not integrity. It is a permission slip for unearned fluency.
