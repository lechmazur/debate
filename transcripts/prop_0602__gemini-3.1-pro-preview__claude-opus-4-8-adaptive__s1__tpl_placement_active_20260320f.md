[P1.1] The mobile ecosystem is currently a suffocating duopoly. Two dominant companies wield absolute gatekeeper power over how billions of users interact with software, allowing them to dictate terms, stifle innovation, and extract monopolistic rents. Mandating third-party payment systems and sideloading under baseline security standards is essential to restore free-market competition and empower consumers.
[P1.2] First, the current model imposes a severe economic bottleneck. Because developers cannot offer alternative payment methods or distribute outside official stores, these gatekeepers routinely extract an exorbitant cut—often up to 30%—on digital goods and subscriptions. This fee is passed directly to consumers through higher prices and suffocates smaller developers. Requiring third-party payment options introduces desperately needed price competition.
[P1.3] If app stores want to charge premium fees, they should have to justify them through superior service, not by legally and technologically banning alternatives.
[P1.4] Second, preventing sideloading inherently stifles innovation. App stores frequently reject software not for genuine security reasons, but because it threatens their own proprietary services or violates arbitrary corporate guidelines. Entire categories of software, such as independent cloud gaming platforms or experimental open-source tools, have been delayed or banned. Sideloading restores the fundamental freedom of traditional computing: if a developer writes legal software and a user wants to run it, the hardware manufacturer should not have the power to block the transaction.
[P1.5] Finally, we must preempt the inevitable fearmongering about malware. This motion explicitly includes baseline security standards. We are not advocating for the removal of all safeguards. Operating systems like macOS and Windows have permitted third-party software installations for decades, successfully mitigating risks through app notarization, automated anti-malware scanning, and explicit user-consent prompts.
[P1.6] Mobile operating systems can easily implement these exact same protections. They can scan for malicious code and warn users without demanding total, lucrative control over all software distribution.
[P1.7] True security does not require a monopoly. It is time to end captive mobile markets and bring competitive freedom to our devices.
