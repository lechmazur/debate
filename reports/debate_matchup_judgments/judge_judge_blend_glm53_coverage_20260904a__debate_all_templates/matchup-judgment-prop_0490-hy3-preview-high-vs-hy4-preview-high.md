### Judge Notes

- **GPT-5.6 Sol (high)** (A = Tencent Hy3 Preview (high) (PRO); B = Tencent Hy4 Preview (high) (CON)): A won a competitive debate by showing that open source complements rather than replaces paper audits and gives defenders actionable warning before or after a flaw is discovered. B's rural remedy-gap argument was strong, but it repeatedly assumed away state-level mitigation and overstated both the licensing obstacle and the alleged contradiction between public code and triaged vulnerability reports. B's repeated nonexistent reference IDs also imposed an execution cost.
  Most decisive rebuttal noted: The decisive exchange concerned frozen rural systems. B argued openness supplies an exploit map without a patch team, but A answered that awareness still enables targeted audits, manual checks, disabled functions, and state-level monitoring. B largely repeated the lack-of-local-capacity premise without neutralizing those centralized mitigations.
- **Gemini 3.1 Pro Preview** (A = Tencent Hy3 Preview (high) (PRO); B = Tencent Hy4 Preview (high) (CON)): Side A wins by brilliantly co-opting Side B's primary defense. Side B relied heavily on Risk-Limiting Audits (RLAs) to catch errors, but Side A repeatedly pointed out that RLAs only sample specific contests, leaving hidden logic errors in unsampled races completely undetected. Side A decisively showed that open source allows defenders to find these flaws and redirect audits to the affected races, turning Side B's own mechanism into a reason to vote PRO.
  Most decisive rebuttal noted: Side A's Rebuttal 2 expertly neutralized Side B's "frozen rural build" argument by pointing out that even if local officials cannot patch the software, state auditors can use the vulnerability report to redirect post-election audits to the exact compromised machine, bridging the pre-election/post-election gap.
- **Grok 4.5 (high)** (A = Tencent Hy3 Preview (high) (PRO); B = Tencent Hy4 Preview (high) (CON)): CON won by making the decisive practical clash clearer and unresolved against PRO: publication does not equal defender capability under freeze windows, thin local IT, and certification lag, so the absolute mandate mainly hands attackers a free map of frozen builds. CON also trapped PRO in a live contradiction on scope (either “all” voids lawful/non-publishable modules and shrinks the market, or “public review” collapses into curated gatekeeping and is no longer the motion as written). PRO’s principle that paper/RLAs only sample after software already transformed ballots, and that reverse-engineering already exists, remained live and respectable, but never closed the remedy gap or dissolved that inconsistency, so CON left the cleaner reason to reject the absolute proposition.
  Most decisive rebuttal noted: CON B4.1/B4.5 forcing PRO’s simultaneous claims that non-publishable modules become ineligible and that curated disclosure still counts as “public security review,” which collapses the motion’s scope either into market shrinkage or into non-public review.

### Judge Notes

- **GPT-5.6 Sol (high)** (A = Tencent Hy4 Preview (high) (PRO); B = Tencent Hy3 Preview (high) (CON)): Side A won by showing that publishing source does not publish credentials or grant system access, while enabling outsiders to check vendors, insiders, and certifiers. Side B never adequately established that source publication makes intrusion trivial, and its escrow alternative ultimately relied on trusting a small, uncheckable group. A also correctly answered that publicly available code is compatible with funded expert review, defeating B’s claimed fatal concession. A’s mistaken reference IDs and somewhat simplified Heartbleed analogy were minor costs.
  Most decisive rebuttal noted: Side A’s strongest exchange answered the blueprint objection by separating source code from keys, configurations, and access, then turned the comparison toward insider risk and hidden audit failure. Side B’s response largely repeated that hostile actors could study the code without proving why controlled secrecy would find flaws first or remain accountable.
- **Gemini 3.1 Pro Preview** (A = Tencent Hy4 Preview (high) (PRO); B = Tencent Hy3 Preview (high) (CON)): Side A won by successfully framing the core requirement of an election as proving the result to the loser, which effectively neutralized Side B's alternative of relying on secret, cleared experts. While B argued strongly about the security risks of handing adversaries a blueprint, A's counter that secrecy only protects the attacker and leaves rumors unanswerable was more compelling.
  Most decisive rebuttal noted: A's Rebuttal 2 and Closing exposed the fatal flaw in B's escrow model: a losing candidate has no reason to trust a hidden group of experts, making a "quietly reconciled" bug inherently illegitimate in a democracy.
- **Grok 4.5 (high)** (A = Tencent Hy4 Preview (high) (PRO); B = Tencent Hy3 Preview (high) (CON)): A won by keeping the decisive clash on democratic proof versus opaque trust and showing that CON’s own paper-trail and escrow tools still require public code for outsiders to reconcile totals. B’s attacker-blueprint and viral-headline risks were real but did not neutralize A’s point that flaws already exist and secrecy only monopolizes discovery for insiders/adversaries; A’s answers to pressure questions cleanly preserved openness as the precondition rather than a substitute for funded review. B’s clipped opening and reliance on “motion alone is insufficient” were weaker once A showed the motion never forbids funding.
  Most decisive rebuttal noted: A4.4–A4.5 turning B’s paper-trail concession against escrow secrecy: visible bugs can be cross-checked; black-box bugs cannot.
